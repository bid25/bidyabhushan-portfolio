**What it is.** Eight pages with a WebGL homepage where scroll position drives a morphing 3D form, smoothed with Lenis.

**Design system.** Paper `#F2EEE6`, coral `#E8634A`, Fraunces for display type, Inter for body, IBM Plex Mono for data. The intent was something closer to a well-designed health magazine than hospital software. The system carried into the mobile app afterward, which is why the two read as one product.

**Note.** None of this ports to React Native — no DOM, no default WebGL canvas. Learning that early avoided designing app screens that couldn't be built.

**Disclosure.** Private repository — happy to walk through the code and architecture in an interview.
